## O‘rnatish

1. ZIPni oching.
2. Ichidagi barcha fayllarni GitHub'dagi `Guliston-360` repository ROOT qismiga yuklang.
3. Eski `index.html`, `style.css`, `app.js` va `icons.js` ustiga yozing.
4. `pano1.jpg`–`pano6.jpg` ham ROOT qismida turganini tekshiring.
5. Commit changes.
6. GitHub Pages `main` + `/(root)` holatida qolsin.
7. Saytni ochib `Ctrl + Shift + R` bosing.
